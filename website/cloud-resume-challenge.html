Building My Cloud Resume Challenge with AWS

A practical project combining a static website, serverless backend, infrastructure as code, and automated deployments.

Introduction

I built this project to gain practical experience with AWS cloud services and to bring together frontend hosting, serverless application development, infrastructure as code, and CI/CD automation in one working website.

Architecture and AWS Services

Amazon S3

Stores the static website files.

Amazon CloudFront

Distributes the website content.

Amazon API Gateway

Exposes the visitor counter HTTP endpoint.

AWS Lambda

Runs the backend visitor counter logic.

Amazon DynamoDB

Stores the visitor count.

AWS SAM

Defines and builds the serverless backend.

GitHub Actions

Runs automated checks and deployments.

AWS IAM & OIDC

Controls permissions and enables GitHub Actions to access AWS without long-lived access keys.

Frontend Deployment

The frontend is hosted in an Amazon S3 bucket and delivered through CloudFront. A GitHub Actions workflow automates publishing website changes to S3 and invalidating the CloudFront cache.

Serverless Visitor Counter

The visitor counter uses API Gateway, Lambda, and DynamoDB. API Gateway receives the HTTP request and invokes the Lambda function. The function updates the stored counter in DynamoDB using an atomic update operation and returns the current count to the website.

Infrastructure as Code and Backend CI/CD

I used AWS SAM to describe and build the backend application. The backend GitHub Actions workflow runs Python unit tests, validates the SAM template, builds the application, and deploys it to AWS after a successful push to the main branch.

Security

I configured GitHub Actions OIDC authentication so the workflow can assume an AWS IAM role without storing long-term AWS access keys in GitHub secrets. I also configured the Lambda execution role with permission to update the visitor counter DynamoDB table.

What I Learned

  • Hosting and distributing static websites with S3 and CloudFront.
  • Building a serverless API with API Gateway and Lambda.
  • Persisting and updating application data with DynamoDB.
  • Defining backend infrastructure with AWS SAM.
  • Automating tests, builds, and deployments with GitHub Actions.
  • Using OIDC to connect GitHub Actions to AWS.
  • Debugging IAM permissions and deployment workflows.

Conclusion

This project gave me hands-on experience connecting several AWS services into a working application. It also helped me understand how cloud infrastructure, application code, security permissions, and CI/CD workflows fit together.
